# Hi, I'm Rabia 👋

**Software Engineer who builds — and manages — AI-powered applications.**

I like understanding how things work before reaching for a library — which is
why one of my projects is a GPT built from scratch instead of just calling an
API, and another is a multi-agent system where I designed the whole
agent-to-agent data contract myself before writing a line of the pipeline.

## 🔭 What I'm building

| Project | What it does |
|---|---|
| [**DropSpot3D**](https://github.com/rabia5727/DropSpot3D) | Interactive 3D car inspection tool — place defect pins directly on a 3D model, log inspection reports, and manage records |
| **ResearchSynth** *(in progress)* | A multi-agent system that runs literature reviews as a self-improving loop — search, extract, detect contradictions, then refine its own search strategy and go again |
| **Cognify** *(in progress)* | AI assistant built for working students |
| [**GPT-from-scratch**](https://github.com/rabia5727/GPT-from-scratch) | A GPT-style language model built from first principles in Python — no shortcuts, transformers implemented by hand |
| [**crew-roster**](https://github.com/rabia5727/crew-roster) | A cabin crew scheduling system |
| [**NLP-Sentimental-Analyzer**](https://github.com/rabia5727/NLP-Sentimental-Analyzer) | Sentiment analysis on text using classic NLP techniques |

Also shipped a few smaller things along the way — [Space-Dodge](https://github.com/rabia5727/Space-Dodge) (a Pygame arcade game), and several Flutter/AI experiments (Nova-AI, Tijarat-AI, Unified-Inbox).
